## About

**GymBro Website** is a web application designed for people who want to build better habits, develop discipline, and follow structured guidance to plan their fitness journey.

## Features

### Profile
- Users can update their username, password, and email.
- Displays the latest weight, height, and BMI on the Fitness Profile.
- Users can edit their fitness goal (e.g., Build Muscle, Lose Fat) by clicking the **Edit Goal** button and entering it in a modal.

### Weight Training
- Provides a basic structure for weight training along with fundamental exercises for targeted muscle groups (e.g., Chest, Back, Legs), tailored for beginners starting out for the first time.

### Cardio
- Introduces cardio activities (e.g., Swimming, Running) and explains heart rate zones.
- Includes a heart rate zone calculator where users can enter their age and select a zone.

### Food
- Shares information on nutrition, BMI, and TDEE.
- Lets users calculate their BMI using weight (kg) and height (m), saves results to their BMI history, and updates their latest BMI on their profile.

### Other

#### Dark / Light Mode
- Users can toggle between Dark and Light mode using the button in the top-right corner.
- Preferences are persisted via `localStorage`, so the selected theme stays intact across page refreshes and navigation between pages.
