# gymbro-web
เว็บไซต์ในการแนะนำการออกกำลังกาย แนะนำมากสำหรับมือใหม่ที่ต้องการจะเปลี่ยนแปลงตัวเอง มีการคำนวณค่า BMI และ Heart Rate เพื่อเป็นแนวทางในการวางแผนในการออกกำลังกาย

##Key Features

**Weight Training:** แนะนำท่าออกกำลังกายโดยใช้แรงต้านในการสร้างกล้าม ซึ่งแบ่งไปแต่ละส่วนของร่างกาย และมีส่วนละ 3 ท่าพื้นฐาน
**Cardio:** ให้ความรู้เรื่องคาร์ดิโอ และมีการคำนวณหาค่าการเต้นหัวใจขอแต่ละ Zone ของผู้ใช้ ซึ่งผู้ใช้สามารถใส่อายุของผู้ใช้ และเลือก Zone ที่ผู้ใช้ต้องการรู้
**Food:** ให้ความรู้เรื่องของอาหาร ค่า BMI และ ค่า TDEE และมีการคำนวณหาค่า BMI ของผู้ใช้งาน ผู้ใช้สามารถใส่น้ำหนัก และส่วนสูงของผู้ใช้ในการหาค่า BMI ของผู้ใช้

##Tech Stack

**Frontend:** HTML5, CSS3, JavaScript(ES6+)
**UX / UI:** Figma
**Deployment:** Github Pages
